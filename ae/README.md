# Artifact evaluation document

[`ae.pdf`](ae.pdf) (source: [`ae.tex`](ae.tex)) is the artifact-evaluation
document submitted to MobiCom 2026, kept here for reference. It describes the
artifact as evaluated.

The hosted Powder deployment and HotCRP access process it describes were
available to evaluators only and are no longer running. Some components have
been updated since evaluation; the top-level [`README.md`](../README.md)
describes the released code.
